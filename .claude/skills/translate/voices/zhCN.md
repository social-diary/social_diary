# Voice: zhCN (简体中文，中国大陆客户端)

第一轮中文本地化定下的口径（2026-11-13，locale/zhCN 分支）。
以 `/copywriter` §1–§6 的英文口吻为准：安静、私密、日记对「你」说话，
从不自称「我」，不喊叫、不用全大写警告、不用内部术语。
带 (?) 的条目值得母语读者再看一眼。

## 称谓与人物

- 对玩家用 **你**（简体中文里最自然的私人称呼），不用「您」：日记是写给
  自己的，不是客服。「你」也用于共享日记里自己的其他角色。
- 日记自称 **这本日记** / **日记**，从不说「我」。玩家自己写的便条保留第一人称。
- 其他玩家一律称 **名字**，或 **对方** / **那个人** / **有人**；英文的
  "they" 在中文里不需要代词时直接省略，不生造「TA」。
- 中文动词、形容词 **不随性别变化**，所以不使用 `<1:he/she>`、
  `<you:he/she>` 一类的形态；`Locale.gendered` 保持 false。性别只出现在
  游戏自己给出的类名、种族名里，原样保留。
- `{you}` 的括号必须保留（共享日记会把「你」换成另一个角色的名字）。
  中文统一用 **`{你}`**（主语、宾语皆可）和 **`{你的}`**（所有格），
  两者都登记在 `Grammar.lua` 的 `YOU_FOR`。英文 `{You}` 在句首大写只是
  排印习惯，中文不区分大小写，一律 `{你}`。
  例如：
  `["{You} killed them"] = "{你}击败了他们"`，
  `["%s saw {you} die"] = "%s看着{你}倒下"`（按上下文选更自然的说法）。

## 时态与语体

- 中文没有形态时态。散文（Your Diary、人物页、导览）用 **完成/陈述**，
  靠「了」「过」「那天」「当时」「后来」带出时间，不堆时间副词。
- 账本行（时间线行、提示、卡片、工具提示）**省略主语**，用动词短语起句，
  与英文一致：「在西部荒野一起做任务」「被霍格击杀两次」。
- 避免英文式长定语；中文用短句、逗号分隔，一句话说完一件事。

## 排版

- 全角标点：逗号「，」、句号「。」、顿号「、」、冒号「：」、分号「；」、
  问号「？」、括号「（ ）」。引号用「“ ”」，嵌套「‘ ’」。省略号「……」。
- **绝不使用间隔号「·」**（`tests/copy_rules.lua` 扫描 `Locales/`，
  `\194\183` 及其转义写法一律禁止）。人名、地名之间用「，」「和」或分行。
- 中文与数字、拉丁字母之间 **不加空格**（客户端字体对 nbsp 已按
  `Locale.lua` 的 `NO_NBSP` 处理为普通空格；中文译文本身不用空格）。
  例：「12 级」写作「12级」，「55 分钟」写作「55分钟」。
- 日期：「10月6日」「10月6日，星期一」「2025年10月6日」。`G.Day(n)` 给
  纯数字（「6」），月份由 `L["October"]` 等键给「10月」；日期模板用
  positional 占位符把月放到前面并补「日」（`%2$s%1$s日`）。
  座次标签（sitting label）用「10月25日」，不带序数「第」。
- 时间：24 小时「18:30」；句中「18:30 时」按模板重排（`G.Clock` 不覆盖，
  沿用默认 `%H:%M`）。时长「1小时20分钟」「55分钟」「1小时33分」。
- 数字：计数用阿拉伯数字，散文里的一到十二可用汉字（「两人」「三次」），
  以词表 `L["one"]` / `L["two"]` 等为准。小数点用「.」（`G.DECIMAL` 不覆盖）。
- 序数：中文用「第N次」「第N场」。`G.Ordinal` 给出「第13」由词表套
  「%s 次」；`first##death` / `first##match` 等词表直接给「第一」。
- 感叹号：英文原本有两处感叹（Firsts 的标题），中文保留语气但减轻，
  其余一律不用。不用全大写强调（中文没有大小写）。
- `Upper` / `Capital` 不覆盖：中文没有大小写，默认实现对汉字无影响。

## 复数

- 中文 CLDR 只有一个类别 `other`：`PLURAL_FORMS = 1`，
  `PluralForm(n) = 1`（`tests/locale.lua` 的 RULES 行同步为 1）。
- 因此每个 `##plural` 值 **只有一个形式、不含 `|`**，且 **必须显示计数**
  （`OneAlone` 为 false，测试要求每个形式都带计数）。
  例：`["%d fight|%d fights##plural"] = "%d场战斗"`。
- `L["twice"]` 写「两次」；中文有这个词，2 不必落到复数形式。
  但 `we fell twice` 之类整句键按整句译。
- `G.Plural(name)` / `G.ItemWord(n, item)` 原样返回：中文名词不变化，
  游戏给的名字（简体中文客户端）已是本地化名，不加「们」「些」。

## 游戏给的名字

**两张表、两种情形，别混：**

- `ZONES` / `DUNGEONS` / `SUBZONES` 三张语法表 **留空**：那里的名字是
  客户端运行时给的，带冠词、变格、介词，不能凭记忆填。用
  `G.PLACE[role]` 的通用介词（在 / 到 / 从 / 进入 / 穿过 / 附近 / 周围），
  例句要让光秃秃的名字读得通：作主语、放在冒号后、或跟在介词后。
- 词表里**写死的游戏名词键**是给玩家看的标签，和其他四种语言一样要译：
  `The Barrens`→贫瘠之地、`Warsong Gulch`→战歌峡谷、`Night Elf`→暗夜精灵、
  `Horde`→部落、`Wolfskin Bracers`→狼皮护腕 等。这些是词表键，不是运行时
  注入的值。译名按简体中文客户端的通用说法，已按术语表落地并经确认。
- 介绍页和空日记里的**示例人名**（Thex、Brom、Numa）保留英文，
  等有简体中文客户端的人来填；示例里的游戏地名按上一条处理。
- 插件名 **Social Diary 保留英文**，不译（与其他四种语言一致）。

## 长度

中文字数约为英文的 40–60%，**几乎不会比英文长**，这是本语言的优势。
需要留意的紧凑位置：提示卡、按键绑定栏、设置项标签、标签页名、
地图图例、重逢提示。这些地方宁可再短一点，不堆修饰词。
`##zone` 模板尤其短：介词已由 `ns.ZoneIn` 给出，模板里不再写「在」。

## 已定口径（2026-11-13 确认）

- rare（一只稀有怪）= 稀有怪物；rare elite = 稀有精英；阶位标签 `Rare` / `Rare##boss` 保持「稀有」（WoW 简中标准，与客户端一致）。
- 战场 match = 一场对局 / 这场对局；`fight` 保持「战斗」（两者明确区分，词表已统一）。
- close call = 险些丧命。
- 内部名词：sitting = 落座；plate = 面板（人物信息面板）；ticket = 记录条（记录行）。
